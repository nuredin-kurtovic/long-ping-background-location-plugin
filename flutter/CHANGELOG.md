## 1.1.0

- First Flutter release, on the Long Ping 1.1.0 native engine (the same one react-native-long-ping 1.1.0 ships).
  Full API: configure / setConfig / start / stop / getState, authorization and token refresh, getCurrentPosition,
  changePace, queue control, permission request, device settings screens, the on-device log and all events as
  streams.
